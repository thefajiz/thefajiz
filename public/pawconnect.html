project overview

what is pawconnect?

an end-to-end web application serving the animal welfare community in bahrain, built from scratch using modern full-stack web technologies.

context
a real-world gap, a digital solution
stray cats and dogs are widespread across bahrain. rescue and adoption efforts exist but rely on informal, fragmented communication, whatsapp groups, scattered social media posts, and unstructured word of mouth. pawconnect addresses this with a purpose-built, centralized system.
platform purpose
adoption, volunteering and community engagement
users browse adoption listings, submit volunteer applications and donation records, and send contact messages, all through a single authenticated platform. admins manage everything through a secure, dedicated portal with real-time analytics.
"
mission statement
replacing informal channels with structured digital tools for animal welfare coordination
pawconnect consolidates adoption browsing, volunteer registration, donation recording, and user communication into a single integrated platform, localized specifically for bahrain's animal welfare community.
problem and solution

why this platform was needed

the absence of a unified reporting and coordination system in bahrain means animal welfare information is scattered across multiple informal channels, slowing rescue operations and reducing effectiveness.

existing platforms like petfinder and aspca are built for western markets, while local options like bspca bahrain lack interactive features. none offer integrated community coordination.

  • no centralized reporting system for stray or injured animals
  • fragmented communication between public, volunteers, and organizations
  • volunteer opportunities poorly surfaced and hard to act on
  • adoption listings exist but not localized or interactive
  • no structured case tracking or resource management tools

the pawconnect solution

  • centralized adoption listings, browse animals with species, breed, age, and status filters, pulled dynamically via rest api
  • online volunteer applications, structured form with admin review workflow and email notifications
  • donation recording, logged in bahraini dinars, visible in admin dashboard
  • contact and inquiry system, structured messages from visitors and registered users to administrators
  • admin portal, 10-page dashboard with analytics, charts, and full record management
  • dual-layer auth, separate jwt secrets for users and admins; bcrypt password hashing

core features

what the platform does

🐾
adoption listings
dynamic animal cards fetched from rest api. filter by species, breed, age, and availability status.
🤝
volunteer system
structured application form with admin review workflow and automated email notifications via nodemailer.
💛
donation tracking
in-app donation recording in bahraini dinars. logged per user and visible across the admin dashboard.
🔐
dual jwt auth
separate jwt secrets for users and admins. bcrypt hashing, helmet headers, and rate limiting on all auth routes.
📊
admin analytics
10-page portal with chart.js dashboards, real-time counts, and full record management across all modules.
📩
contact system
structured inquiry forms for guests and authenticated users, routed to admin inbox with status tracking.
🛡️
security layers
helmet http headers, express-rate-limit on auth routes, server-side validation, and input sanitization throughout.
📱
responsive design
shared css stylesheet across all 9 pages. mobile-first layout with consistent navigation and accessible forms.
technology stack

built with modern tools

a fully javascript stack, node.js on the server, vanilla html/css/js on the client, and mongodb atlas in the cloud.

runtime
node.js + express
restful api server with modular route files, middleware pipeline, and async/await throughout
database
mongodb atlas
cloud-hosted nosql database with mongoose odm, 8 data models including animal, user, volunteer, and donation
authentication
jwt + bcryptjs
dual-secret jwt tokens for user vs admin sessions. bcrypt password hashing with salt rounds
security
helmet + rate-limit
http security headers via helmet. express-rate-limit blocks brute force on auth endpoints
notifications
nodemailer
automated email alerts on volunteer approval, adoption updates, and contact submissions, decoupled from http responses
front-end
html · css · js
9 vanilla html pages with shared stylesheet. fetch api for all client-server communication. chart.js for admin analytics
system architecture

how it all connects

three-tier mvc architecture with a stateless restful api as the backbone. client, server, and database communicate exclusively through json over http.

what's next

planned enhancements

the modular architecture supports incremental expansion. new features can be added without structural changes to the existing codebase.

  • 01 · high priority
    stray animal reporting module
    structured form for reporting injured or displaced animals, with google maps api integration for location pinning and visual case tracking by administrators.
  • 02 · high priority
    mobile application
    the stateless restful api communicates exclusively in json. a react native mobile client could consume all existing endpoints without any back-end modification.
  • 03 · medium priority
    direct image upload
    animal profiles currently reference externally hosted images via url. cloud storage integration (aws s3) would allow uploads directly through the admin portal.
  • 04 · medium priority
    user dashboard and pagination
    registered users track their own adoption inquiries and volunteer applications. server-side pagination on animal listings improves performance at scale.
